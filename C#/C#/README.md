项目简介
本仓库包含两部分内容：基于 C# 实现的射频参数计算工具、LeetCode 30 道基础算法刷题代码，用于完成系统语言编程能力与基础算法能力训练。

一、C# 阻抗与反射系数计算工具
使用 C# 完成面向对象编程，实现射频常用计算公式：阻抗与反射系数双向变换计算。项目用到面向对象封装、基础文件操作、常规数据结构，满足系统语言工程练习要求。
核心功能：
- 负载阻抗、特性阻抗 → 反射系数计算
- 反射系数 → 负载阻抗反向求解
- 支持数据输出、本地文件保存结果
运行环境：.NET 6.0+
二、LeetCode 30道基础算法合集
本文件夹收录 30 道 LeetCode 初级算法题，覆盖工程常用基础算法，代码均独立实现、可直接运行。
题型覆盖：
- 排序算法：各类基础数组排序、自定义排序
- 查找算法：二分查找、线性查找、边界查找
- 动态规划：简单一维、二维 DP 基础题型
- 基础综合算法：数组、字符串、双指针、模拟等基础题型
每道题目均包含完整解题代码，结构清晰，用于训练代码逻辑、算法思维与基础编码能力。
