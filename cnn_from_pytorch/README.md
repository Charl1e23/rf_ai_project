# 项目介绍
本项目使用 PyTorch 复现经典 CNN 网络 ResNet18，基于 CIFAR‑10 数据集完成图像分类训练与验证，实现模型训练、精度评估与结果可视化完整流程。

项目现阶段采用CPU版本PyTorch完成训练，满足小算力、快速验证需求，后续将升级为CUDA GPU版本，大幅提升训练效率。

## 运行环境
基于 Miniconda 搭建独立虚拟环境，隔离项目依赖，环境配置清晰可控：

- 虚拟环境名：`RF‑AI`
- Python 版本：3.9
- 依赖库（适配CPU版本训练）：
  - pytorch
  - numpy：数据运算处理
  - pandas：数据统计与日志整理
  - matplotlib：训练曲线、精度可视化绘图

> 当前使用 CPU 版本 PyTorch 完成快速验证，训练量较小可满足基础实验需求，后续将升级 CUDA GPU 版本提升训练速度。

## 数据集
采用深度学习经典图像分类数据集 CIFAR‑10：
- 数据集包含 60000 张 32×32 彩色图像
- 涵盖飞机、汽车、鸟类、猫、鹿、狗、青蛙、马、船、卡车 10 个分类类别
- 训练集：50000 张，测试集：10000 张
- 项目代码自动完成数据集下载、预处理、归一化、划分加载，无需手动处理数据

## 训练参数
完整复现 ResNet18 经典卷积神经网络结构，包含残差块堆叠、浅层特征提取、深层特征融合、全局池化与全连接分类层，解决深层网络梯度消失问题，适配中小尺寸图像分类任务。

- 模型：原生 ResNet18
- 训练轮数：30 Epoch（完整遍历全部训练集30次）
- 批次大小：BatchSize = 18
- 日志输出：每个 Batch 实时输出训练精度与损失
- 迭代日志：每完成一个Batch训练，实时输出当前批次训练精度，动态监控模型训练效果
